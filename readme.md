# Responsive Web Layout

A modern and fully responsive web layout built using **HTML, CSS, and JavaScript**.
This project includes an animated hero section, responsive navigation menu, feature cards, skill progress bars, project showcase, stats counter, and contact form.

## Features

* Fully responsive design
* Animated gradient background
* Glassmorphism UI cards
* Mobile hamburger menu
* Skills progress bars
* Animated stats counter
* Project image showcase
* Contact form section
* Smooth scrolling

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons

## Project Sections

* Home
* Features
* Skills
* Projects
* Contact
